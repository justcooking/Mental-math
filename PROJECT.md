# Project
Mental Arithmetic Website
## Goal
To help people learn and practice mental arithmetics
## Features
1. Learn methods for performing mental calculations
2. Practice the methods learned after each lesson
3. User login and personal data storage
4. Chapter-wise learning and practice
5. Dedicated practice section with filters
6. Animated and interactive lessons
7. Dark and light themes
### Learning
- Learning is divided into chapters
- Each chapter contains lessons
- Each lesson teaches a mental arithmetic method
- Each lesson is followed by practice questions
- Each chapter has a larger practice session

### Practice
Users can practice independently of the learning progression.

Practice can be filtered by:
- Chapter
- Lesson/technique
- Operation
- Number of digits
- Last digit
- Difficulty
- Other relevant number properties
