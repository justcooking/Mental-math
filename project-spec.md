# Product Specification

## 1. Product Structure

The website has two main sections:

- Learn
- Practice

### Learn
The Learn section is organized into chapters and lessons.

Learn
├── Chapter 1
│   ├── Lesson 1
│   ├── Lesson 2
│   └── Chapter Practice
├── Chapter 2
│   ├── Lesson 1
│   ├── Lesson 2
│   └── Chapter Practice
└── ...
### Practice
The Practice section is separate from the structured Learn progression.
Users can practice techniques independently using different filters.
Possible filters include:
Chapter
Lesson
Technique
Operation
Number of digits
Number properties
Last digit
Difficulty
Number of questions
Timed or untimed practice
## 2. Learn Flow

The Learn section guides the user through the mental arithmetic curriculum.

The basic flow is:
Chapter
   ↓
Lesson
   ↓
Learn the technique
   ↓
Examples / Interactive explanation
   ↓
Lesson Practice
   ↓
Lesson completed

### 3. Practice Flow
Choose Practice
   ↓
Select filters
   ↓
Start Practice
   ↓
Solve Questions
   ↓
Receive Feedback
   ↓
Complete Session
   ↓
View Results
